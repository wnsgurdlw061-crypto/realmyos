# Phase 2: 설치 및 초기화 시스템

## 개요
UnifiedArch OS의 설치 시스템은 초보자부터 전문가까지 모든 사용자가 쉽게 사용할 수 있도록 설계되었습니다. 3단계 설치 옵션과 스마트 자동화 기능을 제공합니다.

## 2-A: 스마트 설치 시스템 설계

### 3단계 설치 옵션

#### Level 1: 초보자 모드 (GUI, 5분)
- **그래픽 인터페이스**: Calamares 기반의 직관적인 설치 프로그램
- **자동 하드웨어 감지**: GPU, 네트워크, 저장 장치 자동 설정
- **기본값 진행**: 추천 설정으로 바로 설치 가능
- **사전 구성된 설정**: 최적화된 기본 설정 제공

**주요 기능:**
- 라이브 USB 부팅 후 바로 설치 가능
- 언어 선택 (한국어 포함 15개 언어)
- 자동 파티셔닝 (기존 OS와 공존)
- 사용자 계정 자동 생성
- 필수 소프트웨어 자동 설치

#### Level 2: 중급자 모드 (CLI, 선택적 옵션)
- **대화형 질문 시스템**: 각 선택지에 대한 상세 설명
- **고급 옵션 접근**: 필요시 세부 설정 가능
- **재사용 가능한 설정**: 설치 설정 저장 및 재사용
- **단계별 안내**: 각 단계별 상세 가이드

**주요 기능:**
- 수동 파티셔닝 지원
- Init 시스템 선택 (systemd/OpenRC/runit)
- 커널 버전 선택 (standard/LTS/optimized)
- 데스크톱 환경 선택
- 보안 설정 커스터마이징

#### Level 3: 전문가 모드 (스크립트 가능)
- **완전 수동 제어**: Arch Linux 설치 스크립트 기반
- **직접 파일 편집**: 설정 파일 직접 수정 가능
- **자동화 스크립트**: 반복 설치를 위한 스크립트 지원
- **고급 설정**: 모든 시스템 파라미터 제어

**주요 기능:**
- Archinstall 확장 도구 사용
- 사용자 정의 스크립트 실행
- 네트워크 설치 지원
- 클러스터 설치 지원

### 대화형 설정 시스템

#### 사용자 프로필 선택
설치 과정에서 사용자 프로필을 선택하여 최적화된 패키지 조합을 제공합니다:

- [ ] **초보자** - Windows 사용자 (기본값)
  - Windows 사용자에게 친숙한 환경
  - GNOME 데스크톱, 필수 앱 포함
  - 자동 드라이버 설치

- [ ] **일반 사용자** - 데스크톱/노트북
  - KDE Plasma, 멀티미디어 앱
  - 생산성 도구 포함

- [ ] **개발자** - 프로그래밍/개발
  - 개발 도구, IDE, 데이터베이스
  - Docker, Git, VS Code

- [ ] **시스템 관리자** - 기업 환경
  - 서버 도구, 모니터링, 보안
  - SSH, 방화벽, 원격 관리

- [ ] **IoT/임베디드** - 경량 시스템
  - 최소한의 리소스 사용
  - ARM 아키텍처 최적화

- [ ] **게이머** - 성능 최적화
  - 게이밍 드라이버, Steam
  - 저지연 커널, 성능 튜닝

- [ ] **보안 연구자** - 보안 도구
  - 침입 탐지, 분석 도구
  - 암호화, 익명화 기능

- [ ] **애호가** - 맞춤 설정
  - 모든 요소 직접 선택
  - 완전한 커스터마이징

### 선택 항목

#### 설치 중 선택 가능한 항목:
1. **Init 시스템**: systemd/OpenRC/runit
2. **저장소**: stable/rolling/hybrid
3. **커널**: standard/optimized/lightweight/RT
4. **데스크톱**: GNOME/KDE/XFCE/i3/Hyprland/None
5. **보안**: SELinux/AppArmor/None
6. **드라이버**: 자동/수동
7. **언어 및 현지화**: 15개 언어 지원

### 스마트 기능

#### 자동 파티셔닝
- 기존 OS 자동 감지 및 공존 설정
- UEFI/BIOS 자동 감지
- 최적의 파티션 레이아웃 제안
- 데이터 보장을 위한 백업 기능

#### 자동 드라이버
- Wi-Fi/그래픽/터치패드 자동 설치
- 최신 드라이버 자동 검색
- 하드웨어 호환성 데이터베이스 활용

#### 자동 마이그레이션
- 기존 설정 파일 감지
- 사용자 데이터 자동 백업
- 애플리케이션 설정 이전

#### 자동 복구
- 설치 오류 자동 감지
- 롤백 기능 제공
- 문제 해결 가이드 제시

### 설치 후 설정

#### 첫 부팅 후 자동 설정:
1. **시스템 튜토리얼** (5분)
   - UnifiedArch OS 주요 기능 소개
   - 기본 사용법 안내
   - 단축키 가이드

2. **애플리케이션 설정 마법사** (10분)
   - 웹 브라우저 설정
   - 이메일 계정 설정 (선택)
   - 클라우드 동기화 설정 (선택)
   - 터미널 설정 (개발자)

3. **성능 최적화** (자동)
   - 시스템 성능 측정
   - 최적화 제안
   - 일괄 적용 또는 수동 선택

4. **보안 설정** (5분)
   - 방화벽 활성화 확인
   - 자동 업데이트 설정
   - VPN 옵션 제시
   - 백업 설정 마법사

## 2-B: 첫 부팅 경험 설계 (OOBE)

### OOBE (Out-of-Box Experience) 설계

#### Phase 1: 부트 화면 (30초)
- **인상적인 부트 애니메이션**: UnifiedArch 로고와 애니메이션
- **진행 표시기**: 로딩 상태 시각적 표시
- **팁 표시**: 시스템 기능 팁 순환 표시
- **선택적 음악**: 부트 사운드 (선택 가능)

#### Phase 2: 시스템 튜토리얼 (5분, 선택 가능)
- **시스템 소개 비디오**: UnifiedArch OS 주요 특징 소개
- **핵심 기능 설명**: 파일 관리자, 설정, 앱 스토어
- **키보드 단축키 가이드**: 효율적인 사용을 위한 단축키
- **건너뛰기 옵션**: 경험 사용자를 위한 바로 시작

#### Phase 3: 애플리케이션 설정 (10분)
- **브라우저 설정 마법사**:
  - 기본 브라우저 선택
  - 즐겨찾기 가져오기
  - 확장 프로그램 설치 제안

- **이메일 설정** (선택):
  - 이메일 계정 추가
  - 캘린더 동기화

- **클라우드 동기화** (선택):
  - Google Drive, Dropbox 등 연동
  - 파일 동기화 설정

- **터미널 설정** (개발자):
  - 테마 선택
  - 셸 설정 (bash/zsh/fish)
  - 개발 도구 설정

#### Phase 4: 성능 최적화 (자동)
- **시스템 성능 측정**:
  - CPU, 메모리, 디스크 성능 테스트
  - 그래픽 성능 측정

- **최적화 제안**:
  - 부팅 속도 개선
  - 메모리 사용 최적화
  - 배터리 수명 연장 (노트북)

- **일괄 적용 또는 수동 선택**:
  - 자동 최적화 적용
  - 개별 항목 선택 적용

- **결과 표시**:
  - 최적화 전후 비교
  - 예상 성능 향상 표시

#### Phase 5: 보안 설정 (5분)
- **방화벽 활성화 확인**:
  - 기본 방화벽 규칙 설명
  - 포트 설정 옵션

- **자동 업데이트 설정**:
  - 업데이트 주기 선택
  - 자동 재부팅 옵션

- **VPN 옵션 제시**:
  - 내장 VPN 기능 소개
  - 유료 VPN 추천

- **백업 설정 마법사**:
  - 자동 백업 활성화
  - 백업 위치 선택
  - 백업 주기 설정

### 선택 가능한 첫 화면 옵션

### 기술 구현

#### 설치 프로그램 아키텍처
```
Calamares (GUI) ──┐
                  ├─ 통합 설치 관리자
archinstall (CLI) ──┘
                  ├─ 프로필 관리자
                  ├─ 하드웨어 감지기
                  ├─ 설정 엔진
                  └─ OOBE 관리자
```

#### 설정 저장 형식
```yaml
# /etc/unifiedarch/install-config.yaml
installation:
  level: beginner|intermediate|advanced
  profile: beginner|general|developer|admin|iot|gamer|security|enthusiast
  language: ko_KR
  timezone: Asia/Seoul
  
hardware:
  auto_partition: true
  auto_drivers: true
  uefi_mode: true
  
system:
  init_system: systemd
  kernel: linux
  desktop: gnome
  security: apparmor
  
software:
  minimal: false
  development_tools: false
  gaming: false
  multimedia: true
  
post_install:
  oobe_enabled: true
  auto_update: true
  backup_enabled: false
```

이 설치 시스템은 모든 사용자가 UnifiedArch OS를 쉽게 설치하고 사용할 수 있도록 설계되었습니다.
